# React + Vite

## Live Site

Visit the live site: [https://ajeet-react-ecommerce.netlify.app/](https://ajeet-react-ecommerce.netlify.app/)

## Development Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Ajeet-Baghel/e-commerce-frontend
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## Build Command

To create a production build:

```bash
npm run build
```
